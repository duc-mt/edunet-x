# Security Policy

## Supported Versions

Since this is primarily a network design and documentation project, there are no specific software versions maintained. However, we strive to keep our documentation and design guidelines up to date with current security best practices.

## Reporting a Vulnerability

If you discover a security vulnerability within this project (e.g., exposed sensitive information, insecure design patterns in network topologies), please do not open a public issue.

Instead, please report it privately by sending an email to the project maintainers. We will review the report and work with you to address the issue.

Please include the following details in your report:
- A description of the vulnerability.
- Where the vulnerability is located (e.g., specific file or diagram).
- Potential impact of the vulnerability.
